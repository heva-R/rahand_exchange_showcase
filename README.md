# Rahand Exchange Management System

A professional money exchange management system designed to manage
customers, currencies, wallets, balances, and exchange transactions.

## Technologies

- Laravel
- PHP
- PostgreSQL
- Blade
- HTML
- CSS
- JavaScript

## Main Features

- Customer management
- Currency management
- Currency exchange transactions
- Wallet management
- Balance tracking
- Transaction history
- Database-driven operations
- Secure authentication
